📋 Alur Pemesanan Cepat

Aplikasi pemesanan komoditas pangan harian terintegrasi database logistik Niaga Pangan Nusantara (NPN).

1
Pilih Outlet & Tanggal
Klik tombol Cust untuk memilih outlet. Tanggal pengiriman otomatis tersetting untuk Besok hari.
2
Cari & Tambah Barang
Ketik nama barang, pilih dari drop-down, masukkan kuantitas (bisa desimal, misal 1.5), lalu tekan Enter.
3
Catatan Spesifik
Tambahkan permintaan perlakuan barang (misal: "Potong 15" atau "Kirim pagi") lewat tombol + Tambah Catatan.
4
Kirim Pesanan
Klik Kirim Pesanan. Data otomatis masuk ke database, sinkron Google Sheet, dan notifikasi terkirim ke Telegram logistik NPN.

💡 Pesanan Barang Khusus (Non-Katalog)

Jika barang belum terdaftar di katalog, ketik "Custom Order" pada kolom pencarian, pilih item tersebut, masukkan kuantitas, dan tuliskan nama spesifik barang serta satuannya pada kolom Catatan.

📦 Surat Jalan & Mode Konsolidasi

Surat Jalan (SJ)

Klik tombol SJ pada riwayat pesanan untuk mengunduh PDF Surat Jalan resmi siap cetak lengkap dengan kop NPN dan tanda tangan.

Mode Konsolidasi

Gabungkan pesanan dari beberapa outlet menjadi satu lembar matriks total belanja menggunakan tombol Mode Konsolidasi.

⚡ Pintasan Keyboard

Pintasan Fungsi
Ctrl + Alt + S Fokus langsung ke kolom Cari Barang.
Ctrl + Alt + N Buka pop-up input catatan untuk barang terakhir di keranjang.
Ctrl + Alt + H Beralih ke tab Riwayat.
Enter pada Qty Menambahkan barang ke keranjang & fokus kembali ke pencarian.
Ctrl + Enter pada Catatan Menyimpan catatan khusus di modal catatan.
Esc Menutup dropdown atau modal yang sedang aktif.
